2. 분석 제어

연결 필요

기본 목표 2초, 최소 1초입니다. 분석이 오래 걸리면 끝난 뒤 다음 화면을 분석하며 밀린 캡처를 쌓지 않습니다. 로그인·결제·메일·메시지·설정 및 입력 중인 화면은 제외합니다.

3. 직접 테스트

사물 이미지 테스트 화면 열기 — 이 탭을 보고 20~30초 기다리면 페이지 이동 없이 관측 수가 증가합니다.

샘플 버튼은 확장 프로그램 없이 분석 엔진을 확인합니다. 실제 화면 캡처 검증은 테스트 화면을 활성 탭으로 둔 상태에서 확인하세요. 샘플에는 고양이와 리모컨이 있으며, 사람·동물은 관심 상품 집계에서 제외합니다.
