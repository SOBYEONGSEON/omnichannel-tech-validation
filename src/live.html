2. 분석 제어

연결 필요

확장 프로그램에서 최초 1회 동의해야 Chrome 주기 캡처가 시작됩니다. 기본 10초 이상 간격이며 분석이 끝나기 전에는 다음 캡처를 하지 않습니다. 로그인·결제·메일·메시지·설정 및 입력 중인 화면은 제외합니다.

3. 직접 테스트

사물 이미지 테스트 화면 열기 — 이 탭을 보고 20~30초 기다리면 페이지 이동 없이 관측 수가 증가합니다.

샘플 버튼은 확장 프로그램 없이 분석 엔진을 확인합니다. 실제 화면 캡처 검증은 테스트 화면을 활성 탭으로 둔 상태에서 확인하세요. 샘플에는 고양이와 리모컨이 있으며, 사람·동물은 관심 상품 집계에서 제외합니다.

많이 노출된 물건

같은 사물이 한 화면에 여러 개 있어도 주기당 1회로 계산합니다. 노출은 구매 의도를 확정하지 않습니다. 검색 링크는 클릭할 때만 외부 사이트를 엽니다.

대기 중

분류 모델의 사물 종류는 제한적이며 정확한 브랜드·모델명 인식을 보장하지 않습니다. 개인정보 마스킹은 규칙 기반입니다. 원본 화면과 OCR 전문은 저장하지 않고, 관심 집계는 RAM에만 남기며 30분 TTL·최대 100개로 제한합니다. 프로그램을 종료하면 삭제됩니다.
